# Reference notes per page

The refs command writes <page>.md here: the locked Refero ids, links and a take / don't-take list.
Reference images you download go in <page>/ref-*.png and are git-ignored.

Replica work (30 Sep): `design/screens/<page>.replica.md` holds the measurements and the region → library component → Epoch content map for each page (commit it); `design/screens/<page>/ref-*.png`, `measurements.json` and `design/screens/compare/` stay on your machine because they contain or derive from third-party screenshots.
