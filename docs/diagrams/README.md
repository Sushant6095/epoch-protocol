# Diagrams

The system design as five Mermaid frames, validated with `mermaid-cli`, plus a detailed prompt for drawing the same thing in Excalidraw.

| File | What it is |
| --- | --- |
| [`Excalidraw-Prompt-Pack.md`](Excalidraw-Prompt-Pack.md) | How to use it, a full master prompt for an AI diagram tool, and the Mermaid code for all five frames |
| `*.mmd` | The five Mermaid sources on their own: system context, program map, money-per-epoch, validator lifecycle, Fee Index & swaps |
| `previews/*.png` | Rendered previews of each frame, un-styled — the polish pass (legend, numbered arrows, grouping) happens in Excalidraw per the prompt pack |

Fastest path to an editable diagram: [excalidraw.com](https://excalidraw.com) → shapes icon → **Mermaid to Excalidraw** → paste one `.mmd` file → Insert. Repeat for all five, then follow the polish checklist at the end of the prompt pack.
